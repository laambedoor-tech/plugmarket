# Plug Market (landing demo rojo)

Landing estática en tema oscuro con acento rojo para la venta de servicios digitales. Inspirada en la estética moderna de marketplaces pero con diseño y copy originales para que no parezca una copia.

## Cómo probar

- Abre `index.html` con tu navegador (doble clic) o usa un servidor local.
- En VS Code puedes usar el plugin "Live Server" para autorecarga.

## Estructura

- `index.html` — página principal
- `css/style.css` — estilos, variables de tema, responsive
- `js/main.js` — partículas en canvas, render de productos demo, contadores
- `assets/logo.svg` — logo simple con gradiente rojo

## Personalización rápida

- Cambia la paleta en `:root` dentro de `css/style.css` (`--accent`, `--accent-2`, `--accent-3`).
- Edita el texto del hero y botones en `index.html`.
- Modifica la lista de productos de ejemplo en `js/main.js` (array `products`).
